# Software

This folder contains basic Arduino examples for testing the DevLab BMI323 module.

The recommended library for this module is:

DevLab_BMI323  
https://github.com/ARabadann/DevLab_BMI323

## Example

The `BasicRead` example demonstrates how to read:

- Accelerometer data
- Gyroscope data
- Temperature

using I2C communication.

## Installation

Install the DevLab_BMI323 library manually from the repository above, then open:

```text
software/examples/BasicRead/BasicRead.ino
